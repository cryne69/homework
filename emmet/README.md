# Задание на закрепление знаний Emmet

Задача: свернуть готовую вёрстку в одну строку Emmet-аббревиатуры.

## Ответ

```
main>h1{Emmet}+ul>li{Быстрый}+li{Удобный}+li{Нескучные обои}^p{Emmet помогает мне писать вёрстку быстрее}*10
```

### Разбор

| Часть | Что делает |
|---|---|
| `main>` | создаёт `<main>` и уходит внутрь него |
| `h1{Emmet}` | заголовок с текстом `Emmet` |
| `+ul>` | соседний `<ul>`, дальше идём внутрь него |
| `li{Быстрый}+li{Удобный}+li{Нескучные обои}` | три пункта списка |
| `^` | поднимаемся на уровень вверх — обратно в `<main>` |
| `p{...}*10` | десять одинаковых абзацев |

Результат — в [index.html](index.html).
